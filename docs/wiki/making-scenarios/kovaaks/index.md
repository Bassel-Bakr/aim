KovaaK's names its own fields and keeps that reference current.[^REF-79] These pages carry a figure
for every option in all seven editors instead.

Knowing what a field is called is not the same as knowing what it does. The same setting can leave
a scenario learnable or unreadable, and the editor never says which.

Two facts shape the build. A scenario always starts as a copy, because no blank one is
offered.[^REF-79][^REF-85] A map is the exception: the map creator starts you with an empty
one.[^REF-91]

## The editors

Named and ordered as the game's own Profile Manager tabs are. A reader with the game open meets the
same words in the same order.
