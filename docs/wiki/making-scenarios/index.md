Make a scenario only when nothing that already exists isolates the thing you keep losing. A custom
scenario has no leaderboard and no history, so it costs you context a known scenario gives away
free.

This section splits in two. The first half asks what a scenario should demand and whether it
measures anything, which is the same question in any trainer. The second half is one trainer's
editor, field by field.
